# Scope – Version 1

## In Scope
- Namespace browser
- Pod browser
- Pod detail screen
- Diagnostics engine
- Logs viewer
- Suggested commands
- Optional safe pod restart with confirmation

---

## Out of Scope (for v1)
- Node-level diagnostics
- Log streaming beyond simple follow mode
- Editing or updating resources
- Auto-remediation tools
- Advanced filtering across all namespaces
- Multi-cluster context switching
- YAML editing
- Ephemeral containers

---

## Philosophy
Focus on **insight**, not **automation**.  
Recommend, don’t modify.  
Highlight issues, don’t attempt to fix them.  
Keep UI simple, predictable, safe.
